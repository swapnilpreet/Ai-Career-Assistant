# 🚀 AI Career Assistant

🔗 **Live Demo:** https://ai-career-assistant-chi.vercel.app/  

AI Career Assistant is an all-in-one AI-powered platform designed to help users grow their careers faster. It provides smart tools like Resume Analysis and Chat with PDF to improve productivity and job readiness.

---

## ✨ Features

- 🔐 User Authentication (Signup / Login)  
- 📄 AI Resume Analyzer (ATS Score + Suggestions)  
- 💬 Chat with PDF (Ask questions from documents)  
- 🔒 Secure Data Handling & Privacy  
- ⚡ Fast & Responsive UI  
- 🎯 Career-focused AI Tools  

---

## 🛠️ Tech Stack

### Frontend:
- React.js  
- Vite  
- Tailwind CSS  
- React Router  

### Libraries & Tools:
- Swiper.js (Slider)  
- React Icons  
- ESLint

## 📦 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/swapnilpreet/Ai-Career-Assistant.git
cd Ai-Career-Assistant
Install dependencies:

npm install

Run the development server:

npm run dev

Build for production:

npm run build
```
